Upload & Ingestion

Raw sources (CFPB regulation text, FAQ, complaint narratives) become normalized SourceArtifacts. Each one carries a stable source handle and keeps its raw_ref untouched. This page is a projection over one real pipeline run — it computes no truth, it reads /api/pipeline/upload.

idle
Lossless law: ingestion normalizes but never replaces. The raw bytes/reference (raw_ref) and the source handle survive every later stage — nothing answer-bearing is dropped on the way in. "Cleaned up" means a new derived layer beside the original, never an overwrite.
