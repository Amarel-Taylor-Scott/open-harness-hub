What this stage does

It serves context packs to tools and people through policy-aware interfaces, not raw uncontrolled source dumps.

Concrete example

Claude Code receives a review pack, expands an approved GitLab source handle, and Baltor records the policy decision and receipt.

Why it matters

The same verified pack can support coding tools, dashboards, workflows, and context layers while keeping lineage and access controls intact.
