# 02 · One-Minute Founder Video

No music, no slides, no buzzwords — you, to camera, **problem first**. ~150 words.

## Script (~60s)
> "Hi, I'm `[name]`. `[+ cofounder if any.]` Companies are spending more on AI every month, and most of
> it is waste — they run the most expensive model on tasks a cheap one would nail, and their AI coding
> tools keep rebuilding things that already exist. We're Teleon. Our first product, Observer, watches
> how you use tools like Claude Code and Cursor, and after a session it shows you exactly where you
> burned money and where the AI reinvented a library you already had — it reads the session files those
> tools already save, so there's nothing to install. `[One real number if you have it: "In our first
> tests it caught ___ reinventions a senior dev confirmed were real."]` And the data it collects —
> including what you accept or dismiss — trains the engine underneath, which runs any task on the
> cheapest model that still passes your tests, on your own cloud. We've built that engine and a working
> prototype. We're `[team / solo]`, we've been at this `[time]`, and we'd love to build it with you."

## Shot notes
- Face the camera; good light; quiet room.
- Energy up; one clean take is fine; don't read robotically.
- Problem in the first 8 seconds. No jargon (run it past the table in `00`).
- If you have a real number, say exactly one — and only if it's true.
