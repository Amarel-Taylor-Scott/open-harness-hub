# ESG pillar (E / S / G) disclosure depth rubric v1

*rubric* · `rubric/esg-pillar-depth-v1` · v0.1.0 · experimental

Six-dimension rubric for grading the DEPTH and QUALITY of a single
ESG pillar disclosure (Environmental, Social, or Governance)
against SASB + ISSB + TCFD + GRI + SBTi. Pillar is specified at
rubric application time.

Complements `rubric/esg-supplier-compliance-v1` (regulatory
enforcement) and `rubric/esg-env-v1` (E-only ESRS sub-rubric).
