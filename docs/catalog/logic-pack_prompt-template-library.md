# Prompt Template Library

*logic-pack* · `logic-pack/prompt-template-library` · v0.1.0 · experimental

A reusable library of typed prompt templates — task-brief, visual-descriptor, and few-shot — derived from community prompt-engineering practice. Each template enforces a minimal set of required slots so pipelines cannot ship vague or unconstrained prompts.
