# Supertonic on-device multilingual TTS

*tool* · `tool/supertonic-tts` · v0.1.0 · experimental

Synthesize speech from text on-device, multilingual, running natively via
ONNX with low latency and no network round-trip. Integration contract for
Supertonic, a lightning-fast on-device TTS engine.

Reference/integration contract only; verify the upstream license before
bundling. Useful as the audio-synthesis leg of generate-audio pipelines and
for privacy-sensitive, offline-first deployments (trust boundary stays local).
