# Census-grounded answer quality

*rubric* · `rubric/census-grounded-answer-quality` · v0.1.0 · experimental

Scores whether an answer about US demographics/economics is grounded in
authoritative Census data rather than model recall: correct geography, a real
figure from the API, a citation, and an explicit refusal when no data exists.
This rubric is the contract that proves the capability lift over a bare LLM.
