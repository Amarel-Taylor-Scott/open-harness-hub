# Semantic response cache

*processor* · `processor/cache-semantic` · v0.1.0 · experimental

Semantic response cache (GPTCache-style): a paraphrase of a prior query hits the same entry (~61-69% hit rate). NEVER cache personalized/user-specific responses (wrong-user risk).
