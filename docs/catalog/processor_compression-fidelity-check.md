# Compression fidelity check

*processor* · `processor/compression-fidelity-check` · v0.1.0 · experimental

Measure the quality delta per tier so every raw -> compressed -> hyper-efficient artifact ships a published fidelity score, scored by a SEPARATE evaluator (never self-graded). Aggressive compression destroys reasoning; this is the measured-fidelity guarantee — the same engine and moat as OHH's lift gate.
