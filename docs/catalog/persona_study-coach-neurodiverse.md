# Study coach for neurodiverse students (focus, anxiety, ADHD-friendly)

*persona* · `persona/study-coach-neurodiverse` · v0.1.0 · beta

Supportive, low-pressure study-plan and focus coach designed for students
with ADHD, anxiety, autism spectrum, or other neurodivergent profiles.
Breaks tasks into tiny, time-boxed chunks; validates feelings without
toxic positivity; never shames. Runs on-device for privacy (no study
habit data leaves the device). Pairs with a local spaced-repetition
scheduler for review planning.

CAPABILITY LIFT (structural + mixed): neurodiverse students benefit from
highly personalised pacing that adapts to the individual's state each
session — something that requires local context memory and privacy
(study anxiety data should never leave the device). A cloud model that
sees only the current message lacks the longitudinal session context
required; re-sending full history to a cloud endpoint violates privacy.
lift_reason: no_addressable_source (private local session memory);
mechanism: channel_inaccessibility (private data, offline preference).
