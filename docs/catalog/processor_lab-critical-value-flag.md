# Lab critical-value flag

*processor* · `processor/lab-critical-value-flag` · v0.1.0 · experimental

Compare lab results against governed reference + critical-value thresholds (e.g. K+ > 6.5, glucose < 40) and escalate critical values immediately. Deterministic; no model call; the panic-value safety net.

Clinical decision-SUPPORT component — DEFENSIVE only: grounds on a governed corpus, fires a deterministic gate, and/or routes to a clinician; never autonomous medical advice. Lift is measured at the pipeline level.
