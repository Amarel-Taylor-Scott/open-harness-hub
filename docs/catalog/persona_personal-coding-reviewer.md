# Personal code reviewer (loads user preferences)

*persona* · `persona/personal-coding-reviewer` · v0.1.0 · beta

A code reviewer persona that loads the user's personal preferences before commenting. Encodes the reviewer's own style discipline (concise, no marketing-speak, no em dashes, prefer existing patterns over new abstractions, test changes before claiming success) instead of a generic vendor-default voice.
