# Daily stage ledger builder

*tool* · `tool/daily-stage-ledger-builder` · v0.1.0 · experimental

Inspects a daily component factory run directory and emits a resumable stage ledger with complete, missing, blocked, skipped, and failed stages plus deterministic resume actions.
