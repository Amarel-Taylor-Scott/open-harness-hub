# GTM Launch Guide

The public launch checklist lives in the parent brand site:

<https://contextiseverything.ai/gtm-launch-guide.html>

It is the operating checklist for taking the three-site platform story from local development to production:

- **AI Done Right** (founding thesis: Context is Everything) as the parent mission and platform story.
- **Baltor** as the paid verified-context control product.
- **OpenHubForAI** as the open builder funnel and governed workflow surface.

The guide covers repository setup, local development, staging, production services, cloud accounts, domains, transactional email, observability, security baseline, pilot packaging, and production cutover.
