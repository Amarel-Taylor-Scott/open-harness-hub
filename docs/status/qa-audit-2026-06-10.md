# QA Audit — full-path & multi-front-end adversarial validation (2026-06-10)

Scope: adversarially validate the full signup/auth paths for EVERY front end (not just Baltor),
record + analyze videos, sweep the front ends, and fix what surfaced. All artifacts under
`artifacts/e2e/`. Counts are from the named proofs/runs, not prose.

## 1. Adversarial auth — ALL 12 front-end realms (`check_adversarial_auth_all_realms`, PASS)

Every realm (parent · Baltor · Teleon · the 9 live hubs) survived, over HTTP:
- **Happy path:** register → verification email rendered (not sent) → login-before-onboard rejected
  → onboard → login → mint key (raw once) → verify → revoke → verify fails → logout → re-login.
- **Attacks rejected:** duplicate register · login before onboarding · **wrong password AND unknown
  account both return identical 401 (no account enumeration)** · mint without a session (401) ·
  revoke a key you don't own (404) · injection-shaped identifier (`evil@x'; DROP TABLE--`) handled
  with no crash and no leak.
- **Cross-realm isolation (ring across all 12):** a session minted in realm A is invalid in realm B;
  an A-only identifier cannot log in to B — no SSO, no cross-realm account.
- **No secret** (cleartext password or raw key) on the wire or on disk across the whole multi-realm run.

## 4. Findings — both FIXED this pass

- **F1 (medium) — Demo Control Tower served a STALE build.** The favicon 404 persisted because the
  :9000 server process was started before the rebuild and never restarted, so it served an old
  `index.html` even after the file on disk was regenerated. **Fix:** killed the stale listener
  (pid found via the port, not a broad sweep) + restarted on the fresh build; also added the
  favicon to `build_demo_control_tower.py`'s template so future builds carry it. Console now 0.
  *Lesson: rebuilding a generated page must restart its server — recorded for the loop.*
- **F2 (low) — stale brand in the design-bundle index.** `dist/sites/openharness-design/index.html`
  still titled itself "ContextIsEverything — Design Portfolio". **Fix:** → "AI Done Right".
- **Favicon 404** (cosmetic, 1/surface) on the Baltor app + all design-bundle HTMLs: fixed by adding
  `<link rel="icon" href="data:,">` to 64 files (the same fix that cleared the portfolio sites).
