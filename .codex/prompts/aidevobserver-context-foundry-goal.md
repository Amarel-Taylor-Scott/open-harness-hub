# /goal: AIDevObserver Context Foundry, Long-Session, And Primitive Flywheel

Run the AIDevObserver primitive-foundry daemon plus context-foundry program as an aggressive, persistent, proof-gated loop.

Do not stop after one pass. Continue improving the system until the human interrupts you, the explicit token budget is exhausted, or a hard safety/privacy/license blocker prevents all useful work. When one path is blocked, switch to another high-value path.

## Mission

Build the AIDevObserver flywheel that continuously finds, distills, generates, tests, and improves:

- realistic AI coding session examples;
- real-source-derived long-session examples and controlled synthetic derivatives for demos;
- Kaggle-derived synthetic data-science sessions;
- GitHub/public-session source candidates;
- local Claude Code/Codex session-derived private candidates;
- source-backed primitive drafts with contracts, effects, memory/cache policy, remix tools, and proof requirements;
- source-backed capability blueprints, task archetypes, app microsurfaces,
  template routes, and typed slots for broad tasks that need a route, not just a
  single helper primitive;
- source-backed primitive candidates across software engineering, app building,
  frontend surfaces, backend APIs, data engineering, data science, ML evals,
  DevOps, Kubernetes, cloud functions, serverless jobs, queues, MCP/tool
  surfaces, n8n/workflow automation, browser automation, media pipelines, and
  agent harnesses;
- deterministic input/output edge mutators and adapter recipes that let routes
  compose before codegen;
- runtime emitters for local, API, CLI, container, Kubernetes, cloud-function,
  workflow, and MCP targets;
- primitive opportunities when source evidence is not yet strong enough for a draft;
- CandidateBundle-style examples and benchmarks for AIDevObserver, Teleon, OpenHubForAI, Baltor, and AI Done Right.

This primitive/source lifecycle is global infrastructure. AIDevObserver is both a
producer of session signals and a consumer of compact reuse cards; it is not the
owner of all primitive creation. Edge cards, mutators, adapters, summaries,
blocking/vector exports, benchmark fixtures, and promotion queues must be usable
by Teleon, OpenHubForAI, Baltor-adjacent context surfaces, and future products.

The agentic loop contract:

```text
user build task
  -> deterministic edge/template search
  -> route-level blueprint/template/slot search for broad tasks
  -> compact Kimi/GLM planner/tool loop only if needed
  -> selected primitive edges + deterministic adapters
  -> compiler/materializer
  -> copied/importable primitive snapshots where license/visibility allow
  -> generated tests/runtime wrappers/proofs
  -> coding harness fallback only for missing glue or genuinely novel code
```

The user should not be required to say "search the registry" or manually select
components. Reuse search, edge-card compression, route planning, adapter
selection, code materialization, test generation, and model-use accounting are
part of the automatic AIDevObserver loop.

The product thesis:

```text
AIDevObserver reviews AI coding sessions and routes agents away from reinventing code, workflows, templates, media pipelines, data-science patterns, and generated components the primitive database already knows.
```

The architecture invariant:

```text
Python/session/project artifacts are evidence.
Candidate records are not truth.
Primitive drafts are not truth.
Synthetic sessions are not truth.
Unsourced primitive ideas are opportunities, not primitive drafts.
Every source-backed card carries source visibility.
Public/demo retrieval excludes private_internal_only candidates.
Opt-in local retrieval may use private_internal_only candidates without exporting private text, raw local paths, secrets, or PII.
PlanLocks/proofs/promotion decide served truth later.
Everything generated by this loop defaults to serves_truth=false.
```

## Core Loop

Repeat this loop continuously:

```text
ORIENT
  Read the runbook, long-session plan, source-surface map, current candidate rows,
  example manifest, AIDevObserver UI, and observer review engine.

GENERATE
  Run the primitive-foundry daemon first. It regenerates source-backed edge cards,
  refreshes context-source queues, runs proofs, smoke-tests search, and logs receipts.
  It must preserve public/private visibility scopes and prove public search does
  not surface private_internal_only records.
  It must keep broad developer task coverage alive: app surfaces, backend/API,
  frontend, data engineering, data science/ML, DevOps/K8s/cloud functions,
  workflows, MCP/tools, browser automation, and agent harnesses.
  Generate synthetic sessions only as labeled demo/fixture views or privacy-preserving
  derivatives. Use local sessions only under the privacy rules below.
  Default one-tick command:
  `python3 scripts/aidevobserver_primitive_foundry_daemon.py --once`.

SELECT
  Pick the highest-value candidate batch: real-source primitive extraction, connector
  coverage, source-ref precision, visibility-safe retrieval, install/setup path,
  long app sessions, Kaggle sessions, GitHub/public sessions, local private
  derivatives, workflow/n8n/media examples, primitive-contract improvements,
  input/output edge coverage, deterministic mutator coverage, adapter/runtime
  emitter support, or route-proof/test generation.

BUILD
  Make one durable improvement: code, docs, examples, manifests, checks, contracts,
  primitive-draft standardization, source connectors, UI surfaces, benchmark fixtures,
  or promotion-gate scaffolding.

VERIFY
  Run focused proofs. Fix failures immediately.

RECORD
  Update docs/runbooks/manifests/ledgers so the next agent can continue.

REPEAT
  Continue without asking unless all safe useful paths are blocked.
```

## Aggressive Work Menu

Keep choosing from this menu. Do not wait for permission unless the work requires network escalation, private data publication, destructive commands, or unknown licensing.

### 0. Prefer Real-Source Primitive Work

Before creating a new synthetic primitive, search for source evidence:

- local repo symbols, scripts, docs, tests, workflows, examples;
- accepted AIDevObserver findings and dismissed negative memory;
- OpenHubForAI catalog records and benchmark/proof artifacts;
- public GitHub metadata, package APIs, MCP schemas, OpenAPI/GraphQL specs;
- Kaggle competitions/datasets/notebooks as attributed public project evidence;
- n8n/workflow/media-pipeline exports when license and attribution are compatible.

If evidence is weak or absent, create a `primitive_opportunity` instead of a
`primitive_draft`. A primitive draft must have source refs, provenance/license
status, contract, effects, memory/cache policy, readiness, proof requirements,
and `serves_truth=false`.

For local repo source-backed primitives, prefer actual code surfaces before docs:
functions, methods, classes, constants, scripts, entry points, then selected docs.
Skip private scratch/reference/history folders such as `.agent/`, `.agents/`,
`.codex/`, `_reference/`, and `archive/`.

Use this flow:

```text
discover source -> record provenance -> infer contract -> dedupe -> emit candidate
-> add benchmark/source-ref fixture -> prove -> queue promotion later
```

Follow `_repos/aidevobserver/context/codex/aidevobserver-real-primitive-launch-goal-addendum.md` for
the full launch-grade checklist.

## Safety And Governance Rules

Hard rules:

- Do not delete user work.
- Do not run destructive git commands.
- Do not publish raw local Claude/Codex transcripts.
- Do not store raw local paths in public artifacts.
- Do not turn public scraped data into truth without license/provenance review.
- Do not copy Kaggle notebook implementations unless license and attribution are compatible.
- Do not claim synthetic sessions are real sessions.
- Do not create trusted primitive records from synthetic-only ideas.
- Do not promote candidate primitive drafts into trusted registries without proof.
- Do not expose loopback/local URLs in final user-facing messages.
- Generated source candidates, primitive opportunities, and primitive drafts remain `serves_truth=false`.

When in doubt:

```text
candidate evidence, not truth
digest, not private text
synthetic derivative, not raw transcript
proof gate, not promotion by assertion
source-backed draft, otherwise opportunity-only
```

## Stop Conditions

Keep going until one of these is true:

- the human interrupts or changes direction;
- the explicit goal token/time budget is exhausted;
- every listed source path, example path, primitive-contract path, benchmark path, and UI path has a green proof and no obvious next improvement;
- all remaining work requires external credentials, network escalation, private-data publication, or human license/legal decisions.

If blocked in one lane, switch lanes:

```text
local source refs -> accepted memory -> source surfaces -> Kaggle docs -> GitHub/public metadata -> package/API/MCP/workflow sources -> examples -> primitive contracts -> UI -> tests -> docs
```

## Completion Criteria

Do not mark complete merely because one loop ran.

Completion requires:

- context-foundry loop proof green;
- AIDevObserver example proof green;
- observer review proof green;
- no raw local evidence/path leakage in generated candidate outputs;
- a materially larger or better set of source-backed primitive candidates, opportunity records, examples, and benchmark fixtures;
- docs/runbooks updated with what changed;
- next actions recorded for the next loop.

Minimum final report:

```text
Files changed
Candidate counts before/after
Examples added or improved
Primitive families added or improved
Proofs run
Privacy scan result
Next highest-value loop
```
