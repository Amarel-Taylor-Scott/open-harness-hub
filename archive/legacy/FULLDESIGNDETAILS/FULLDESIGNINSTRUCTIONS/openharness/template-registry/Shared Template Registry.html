▤ Templates generate starting shapes. Harnesses prove generated outputs work. A template is never trusted on its own — every instance is run against a harness, and only a pass earns trust. This registry is internal; the .io hubs publish the proven artifacts.
What this registry is. The single source of reusable shape — schemas, runtimes, resources, API/UI scaffolds, inference preferences and PurposeTask definitions — for Teleon, Baltor and the hubs. What it is not: it is not a truth authority and not a substitute for proof. Generated output earns trust only by passing a harness (OpenHarnessHub); promotion is still Teleon's policy gate.
