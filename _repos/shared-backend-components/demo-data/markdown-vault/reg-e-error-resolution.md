# Reg E Error Resolution

A financial institution must investigate a reported error and resolve it within the prescribed window.
The institution may take longer if it provisionally credits the account. This note links to [[Dispute Intake]].

> The deadlines stated here are summarized for illustration and must be verified against the current regulation.
