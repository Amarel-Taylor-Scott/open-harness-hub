# Streaming Result Render

*pattern* · `pattern/streaming-result-render` · v0.1.0 · experimental

Token-wise streaming combined with progressive disclosure of the assembled
pipeline. Rather than waiting for the full blueprint before rendering, the
UI materialises each pipeline section as tokens arrive: intent summary first,
then component cards one-by-one, then the cost estimate, then the final
serialized manifest. Users can read, react, and interrupt at any stage.
