# Draft manifest quality rubric v1 (for curator review)

*rubric* · `rubric/draft-manifest-quality-v1` · v0.1.0 · experimental

Seven-dimension rubric for grading a draft manifest emitted by
`harness/draft-manifest-author` before a curator promotes it from
`catalog/_inbox/` to live `catalog/{type}/`. Used both as
automated screening (judge LLM applies the rubric) and as the
curator's review checklist.
