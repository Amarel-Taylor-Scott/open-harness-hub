# Personal writing companion (loads user preferences)

*persona* · `persona/personal-writing-companion` · v0.1.0 · beta

A writing assistant persona that loads the user's personal style preferences before drafting. Strips disallowed idioms (em dashes, hedging adjectives, marketing-speak), enforces the user's preferred sentence length, vocabulary, and citation discipline.
