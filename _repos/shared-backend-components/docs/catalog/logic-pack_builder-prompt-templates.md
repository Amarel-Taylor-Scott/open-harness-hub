# Builder Prompt Templates

*logic-pack* · `logic-pack/builder-prompt-templates` · v0.1.0 · experimental

Prompt templates and response policies for every LLM call made inside the
conversational pipeline builder. Covers intent extraction, component-retrieval
framing, pipeline assembly explanation, cost narration, and refine-loop
re-entry. Prompts are stored as data so they can be versioned, A/B tested,
and swapped without code changes.
