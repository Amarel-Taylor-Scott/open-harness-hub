# Anti-pattern: prompt with no success criteria

*pattern* · `pattern/anti-missing-success-criteria-prompt` · v0.1.0 · stable

Deploying a prompt-driven component with no machine-checkable success criteria: no output schema, no scoring rubric, no refusal condition, no pass/fail threshold. Any output is accepted because there is no definition of what a good output looks like.
