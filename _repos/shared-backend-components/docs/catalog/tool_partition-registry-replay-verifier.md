# Partition registry replay verifier

*tool* · `tool/partition-registry-replay-verifier` · v0.1.0 · experimental

Builds a compact registry from partition manifests and replays append-only index deltas to verify idempotency, missing files, duplicate delta IDs, content hashes, and final index-state counts.
