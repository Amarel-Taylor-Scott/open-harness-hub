# Statute / regulation clarity & interpretation-risk rubric v1

*rubric* · `rubric/statute-clarity-v1` · v0.1.0 · experimental

Five-dimension rubric for grading how clearly a statute, regulation,
ordinance, or agency rule is drafted, and how much interpretation
risk it carries. Use against statutory text BEFORE enactment for
legislative-counsel review, or AFTER enactment for risk assessment.

| axis | value |
|---|---|
| industry | legal, legal.compliance, government, government.regulatory |
| capability | evaluation |
| modality | text |
