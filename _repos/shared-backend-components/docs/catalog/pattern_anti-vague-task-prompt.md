# Anti-pattern: vague task prompt

*pattern* · `pattern/anti-vague-task-prompt` · v0.1.0 · stable

Sending an LLM a task without a concrete objective, deliverable scope, or success signal. The model guesses the format, length, tone, and depth, producing inconsistent outputs that cannot be evaluated deterministically.
