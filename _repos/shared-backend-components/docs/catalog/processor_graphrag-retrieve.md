# GraphRAG retrieve

*processor* · `processor/graphrag-retrieve` · v0.1.0 · experimental

Knowledge-graph (GraphRAG) retrieval: follow explicit relationship chains for multi-hop + corpus-wide sensemaking that naive vector RAG misses (wins ~70-80% of complex sensemaking). Add only when the retriever genuinely can't follow a relationship — heavier build/compute.
