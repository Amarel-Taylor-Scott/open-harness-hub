# wshobson/agents multi-harness skill marketplace

*tool* · `tool/wshobson-agents-skill-marketplace` · v0.1.0 · experimental

A curated collection of Claude Code agent configurations, multi-agent
harnesses, and reusable skill definitions maintained as a community
marketplace. Each agent or harness is declared as a structured YAML/JSON
manifest that can be loaded into Claude Code sessions or composed into
larger workflows. Covers harness archetypes such as breadth scouts,
depth analysts, code-review agents, documentation writers, and test
generators, each with declared capabilities and prompt strategies.

Integration contract for the wshobson/agents repository; covers skill
loading, agent spawning, and marketplace browse/search operations.
Reference/integration contract only; verify upstream license before
bundling.
