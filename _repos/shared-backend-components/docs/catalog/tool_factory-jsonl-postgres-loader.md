# Factory JSONL Postgres loader

*tool* · `tool/factory-jsonl-postgres-loader` · v0.1.0 · experimental

Emits deterministic Postgres upsert SQL from object-factory JSONL outputs, including source records, normalized objects, entities, dedupe clusters, review tickets, promotion decisions, index records, partition manifests, and index deltas.
