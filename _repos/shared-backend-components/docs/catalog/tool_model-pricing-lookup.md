# Active model pricing lookup

*tool* · `tool/model-pricing-lookup` · v0.1.0 · experimental

Fetches or normalizes current model pricing for provider, model, region, context window, and billing unit. Pricing is volatile and should be stored as a run-scoped snapshot.
