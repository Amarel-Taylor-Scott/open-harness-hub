# Distilled memory write

*processor* · `processor/memory-distilled-write` · v0.1.0 · experimental

Distill a conversation/run into durable facts (Mem0-style selective extraction — ~1.8k tokens/convo) and write them to the memory store: stores what was LEARNED, not raw history.
