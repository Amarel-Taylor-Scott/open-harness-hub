Continuously run the daemonized primitive-foundry/agentic loop and improve it: find, distill, test, and improve real-source primitive candidates, realistic AI coding sessions, controlled synthetic derivatives, Kaggle-derived data-science sessions, GitHub/public-source candidates, private local-session derivatives, CandidateBundle examples, benchmark fixtures, deterministic mutators, edge adapters, runtime emitters, and demos for AIDevObserver, Teleon, OpenHubForAI, Baltor, and AI Done Right.

The primitive/source lifecycle is global OpenHubForAI/Teleon infrastructure, not an AIDevObserver-only feature. AIDevObserver contributes session signals and consumes compact reuse cards. Product thesis:
AIDevObserver reviews AI coding sessions and routes agents away from reinventing code, workflows, templates, media pipelines, data-science patterns, and generated components the primitive database already knows.

Agentic loop thesis:
The user types one ordinary build task. AIDevObserver silently searches reusable capability blueprints, pipeline recipes, template routes, slots, primitives, and adapters by input/output edges, blackbox behavior, blocking keys, visibility, and mutatable compatibility; Kimi/GLM may call registry tools over compact edge cards when exact deterministic matching is insufficient; the deterministic compiler/materializer wires selected primitives, copies/imports allowed source snapshots, emits tests/runtime wrappers, and only then falls back to a coding harness for missing glue or novel code. No manual component selection is required.

Invariant:
Everything generated by this loop is candidate evidence only. Default to serves_truth=false. Real source evidence comes before primitive drafts; unsourced capability ideas are primitive_opportunities. Synthetic sessions are demos/fixtures, not truth. PlanLocks, proofs, and promotion decide served truth later.

Visibility invariant:
Every source-backed edge card must carry a surface visibility boundary. Public/demo retrieval must exclude private_internal_only records. Opt-in local retrieval may use private_internal_only records, but never export raw private transcripts, local paths, secrets, or PII into public demos, docs, or fixtures.
