How your agent consumes it

The output is not a chat answer. It is a governed context package rendered into whichever shape your agent or retrieval stack already uses.
1MCP / API
Live-serve into Claude Code, Codex, Cursor, or internal agents
The runtime pulls the right verified context at the right detail level.
2RAG records
Chunks, metadata, citations, freshness
Drop into vector, keyword, or hybrid retrieval systems.
3Graph package
Entities, claims, source links, procedures
Use source-aware graph retrieval and impact propagation.
4Audit packet
History, worker traces, adoption decisions
Show what changed, why it was adopted, and which facts were held back.
One rule underneath it all
Facts do not become served context just because one source or one model says so. Baltor keeps lineage, source counts, trust checks, archive state, and follow-up tasks so partial evidence can mature into verified context.
