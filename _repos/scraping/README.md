# aidoneright-scraping

A DEV TOOL in the **AI Done Right** multi-repo org: a reusable scraping / browser-automation /
stealth-fetch toolkit built around the **descent ladder** — API → browser → stealth → vision. It uses the
least-intrusive method that works, honors consent and robots, and feeds intake and discovery with governed
source material.

## What this repo is

Product-neutral infrastructure. It exposes, as its published interface:

- **fetch-ladder** — climbs API → browser → stealth → vision, stopping at the first rung that works.
- **browser-automation** — headful/headless page drivers for dynamic sites.
- **extract-cascade** — structured extraction over fetched content.
- **rate-governance** — polite pacing and per-source rate limits.
- **robots/consent-gate** — the mandatory gate: consented, public, robots-respecting sources only.

Every fetched row is born a candidate (`serves_truth = false`) with its source handle preserved.

## How it fits

Dependency direction is fixed by `../dev-rules-context/contracts/surface-registry.json`:

- **This repo may consume:** `dev-rules-context` (standards, contracts, checkers, `_shared`),
  `shared-backend-components` (registry, primitives, codegraph, eval-harness, storage-tiers,
  credential-plane), and `api-endpoint-wrappers` (port-adapters, provider-registry, cost-gates,
  retry/backoff, credential-port) — reaching remote endpoints through those ports, never a hardcoded host.
- **This repo is consumed by:** `aidevobserver`, `baltor`, `shared-backend-components`. Keep the exposed
  interface stable for them.

The authoritative, machine-readable edges live in `EDGES.md` (generated by the edge-graph-generator from
the surface registry).

## Layout

- `CLAUDE.md` — the agent operating manual (filled from the org template; inherits the 8 standards).
- `EDGES.md` — this repo's cross-repo contract: neighbors' published edges, nothing of their internals.
- `context/` — per-component context (purpose, edges, paths, proofs, status), added as components land.
- `README.md` — this file.

Inherited standards, the shared glossary/config, and the portable checkers live in the sibling
`../dev-rules-context/` repo — this repo does not re-declare them.

## How to work in it

1. Read `../dev-rules-context/standards/README.md`, then `CLAUDE.md`, then `EDGES.md`.
2. Only consume a neighbor through its `exposes` list in `EDGES.md`; never import its source. Reach remote
   endpoints via `api-endpoint-wrappers` ports.
3. Add a component as its own `context/<full-word-name>/`; read shared constants from
   `../dev-rules-context/_shared/`.
4. Climb the ladder — try the cheapest, least-intrusive rung first — and pass every source through the
   `robots/consent-gate` and `rate-governance`. Never scrape PII, paywalled, or non-consented sources.
5. Carry a warrant for every change; run the umbrella `run_proofs`; audit consuming neighbors before and
   after an interface change.
