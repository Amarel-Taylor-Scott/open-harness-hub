What this stage does

It accepts raw sources and already-contextualized projections: CodeGraph for implementation reality, DocGraph for stated decisions and documentation, and OrgGraph for owners, approvals, access, and affected teams.

Concrete example

A Confluence ADR enters DocGraph, a GitLab MR enters CodeGraph, a Datadog incident creates live operational context, and ownership updates enter OrgGraph. Baltor preserves each as linked evidence.

Why it matters

The next stages can reconcile code reality, documented intent, and organizational ownership because ingress does not collapse them into one anonymous index. Each graph remains specialized and source-linked.
