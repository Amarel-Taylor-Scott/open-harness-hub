# OpenContextHub

> Open context artifacts for AI systems.

**Kind:** OpenContextHub.io · open context registry

**Audience:** Builders and teams who need reusable, source-grounded context artifacts.

## What it is
- An open registry of source-grounded context artifacts.
- Context packs · schemas · source-handle maps · decomposition examples · native sidecars.

## What it is not
- Not a runtime.
- Not a truth authority.
- Not a private customer data lake.
- Not a replacement for Baltor.
- Not a skill, tool, or harness registry.

## Owns
- Context artifacts
- Context packs
- Context schemas
- Source-handle maps
- Decomposition maps
- Native sidecar examples
- Context fixtures

## Does not own
- Runtime execution
- Truth promotion
- Customer-private context by default

## Relationship
OpenContextHub publishes reference context artifacts. Baltor governs whether context becomes verified, reconciled, current, and served. Teleon consumes context for PurposeTasks.
