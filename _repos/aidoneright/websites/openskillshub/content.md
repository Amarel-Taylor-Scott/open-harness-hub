# OpenSkillsHub

> The searchable skill graph for AI agents.

**Kind:** OpenSkillsHub.io · open skill graph

**Audience:** Agent builders publishing and reusing playbooks and SKILL.md packages.

## What it is
- A searchable skill graph: playbooks, workflows, and SKILL.md packages.
- Agent instructions with provenance and duplicate detection.

## What it is not
- Not executable tools (that is OpenToolsHub).
- Not eval harnesses (that is OpenHarnessHub).
- Not context truth.
- Not a runtime.

## Owns
- Skills
- Playbooks
- Workflows
- SKILL.md packages
- Agent instructions
- Skill provenance / dedup

## Does not own
- Executable tools
- Eval harnesses
- Context truth

## Relationship
OpenSkillsHub teaches agents HOW. Skills USE tools from OpenToolsHub, are PROVEN by OpenHarnessHub, draw context from OpenContextHub, and run via Teleon.
