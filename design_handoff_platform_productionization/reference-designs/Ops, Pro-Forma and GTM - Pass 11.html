04 GTM — channels in adoption order

  1. The hub content engine (SEO, programmatic). 21 registries × every entry = indexable pages with real utility — and nobody else's directory pages carry receipts. The moat channel.measure: discover events per hub · entries indexed
  2. Launch events. Every private→live hub flip is a launch (Show HN, PH, r/selfhosted, MCP communities). 12 private-bench hubs = a year of launch cadence already sitting in the repo.measure: visitor spike + signup conversion per launch
  3. Container distribution as marketing. ghcr/Docker Hub with SBOM + cosign badges; READMEs are landing pages; docker pull is the CTA; awesome-lists + MCP directories.measure: pulls · verified-deployment handshakes
  4. Founder-technical content. The receipts thesis writes itself: held-out conflicts, verified-corpus vs grounded-answer. 1–2 posts/mo.measure: engage events by referrer
  5. Paid (gated). Only after the organic baseline exists; needs its own pro-forma line (budget cap, CPL target, kill threshold) before a dollar moves.

The demo is the marketing: every page routes to "watch it run" — the guided demos and run consoles are the conversion engine; A/B on hero/CTA/demo-first via OHExp, whose exposure/conversion events already have a real sink.
